# 🔬 CinnaGen EC Equipment

سایت جستجو و پیگیری تجهیزات (معادل تب‌های Search، Overdue و تب‌های سوپروایزرها در اکسل). روی موبایل و کامپیوتر کار می‌کند و تم تیره/روشن را خودکار از گوشی می‌گیرد.

---

## ۱. راهنمای استفاده

### نصب روی موبایل (اختیاری ولی پیشنهادی)
آدرس سایت را در مرورگر باز کنید ← **Share** ← **Add to Home Screen**. از این به بعد مثل یک اپ از صفحه اصلی باز می‌شود.

### معنی رنگ‌ها
رنگ‌ها همان رنگ‌های اکسل هستند و **فقط نوع لیبل را مشخص می‌کنند**، نه وضعیت آن را.

| رنگ | معنی |
|---|---|
| 🟠 نارنجی | PM |
| 🔵 آبی | CA |
| 🟢 سبز | PQ |
| ⚪ طوسی (خط‌چین) | تجهیز این لیبل را دارد ولی **تاریخ سررسید ندارد** (باید بررسی و تاریخ ثبت شود) |
| 🟥 قرمز کمرنگ | تجهیز (کارت یا ردیف) **overdue** است |
| بی‌رنگ و کم‌رنگ با `—` | تجهیز این لیبل را اصلاً ندارد |

نکات:
- لیبلی که تاریخش **گذشته** باشد، مثل اکسل با رنگ خودش **توپر** می‌شود (نارنجی/آبی/سبز). بقیه فقط یک نوار رنگی بالا دارند.
- کارت هر تجهیزی که حتی یک لیبلش overdue باشد، کل کارتش قرمز کمرنگ می‌شود و نشان `Overdue` می‌گیرد.
- فاصله تا سررسید (مثلاً `in 30 d` یا `12 d overdue`) فقط با **متن** نوشته می‌شود و رنگ جدا ندارد.

### تب 🔍 Search

**کادر جستجو**
- هر چیزی بنویسید: کد تجهیز، توضیحات، برند، اتاق، لوکیشن، اسم سوپروایزر، اسم کامل یا مخفف کاربر، کد، تاریخ.
- چند کلمه بنویسید یعنی **همه** باید وجود داشته باشند. مثلاً `EC-BAL moda` فقط ترازوهای MoDa را نشان می‌دهد.
- کلمه‌های پیدا شده داخل کارت‌ها هایلایت (زرد) می‌شوند.
- تاریخ را هم با فرمت `15.03.2026` و هم `2026-03-15` می‌توانید جستجو کنید.
- اگر چیزی پیدا نشد، تعداد کلمه‌ها را کمتر کنید.

**دکمه‌های فیلتر زیر کادر**
- **All**: همه تجهیزات.
- **Overdue**: تجهیزاتی که حداقل یک لیبلشان گذشته است. به ترتیب قدیمی‌ترین مرتب می‌شوند.
- **Due ≤ 90 days**: تجهیزاتی که سررسیدشان تا ۹۰ روز آینده است. به ترتیب نزدیک‌ترین مرتب می‌شوند.
- **⚪ No date**: همه تجهیزاتی که یک لیبل طوسی (بدون تاریخ) دارند. برای پیگیری و تکمیل تاریخ‌ها.
- لیست‌های کشویی **All supervisors** و **All types** برای محدود کردن نتیجه به یک سوپروایزر یا یک نوع تجهیز. با جستجو و دکمه‌ها قابل ترکیب هستند.

**کارت هر تجهیز**
- بالا: کد تجهیز، توضیحات و برند، نوع تجهیز، و نشان‌های `Overdue` یا `No date: PM, PQ` در صورت وجود.
- خط 📍: اتاق، شماره اتاق، لوکیشن و 👤 سوپروایزر.
- سه کادر **PM / CA / PQ** هرکدام با: تاریخ سررسید، فاصله تا امروز، فاصله انجام (هر چند ماه)، کاربر انجام‌دهنده، و تاریخ آخرین امضا.
- اگر کاربر یا تجهیز توضیح ویژه داشته باشد (Heads up، Change Loc)، در یک کادر کرم‌رنگ زیر کادرها دیده می‌شود.
- **All details** را بزنید تا اطلاعات کامل‌تر (برند، کد، Cal type، کاربر VA، تاریخ IQ و OQ، تاریخ امضای PQ) باز شود. وقتی فقط ۱ یا ۲ نتیجه هست، خودکار باز می‌شود.
- اسم مخفف کاربران را نگه دارید (روی کامپیوتر موس را روی آن ببرید) تا اسم کامل و داخلی‌اش دیده شود.
- هر بار ۶۰ کارت نمایش داده می‌شود. با **Show more** بقیه را ببینید.

### تب 👥 Supervisors

برای پیگیری کارهای هر سوپروایزر، مثل تب‌های شخصی در اکسل.

1. بالا اسم سوپروایزر را انتخاب کنید (یا **All**). عدد قرمز کنار اسم، تعداد overdue آن سوپروایزر است.
2. با دکمه‌های **PM / CA / PQ** فقط یک نوع را ببینید.
3. با لیست کشویی بازه آینده را انتخاب کنید (۳۰، ۶۰، ۹۰ یا ۱۸۰ روز).
4. خط خلاصه بالای لیست تعداد overdue، تعداد آینده و تعداد موارد بدون تاریخ را می‌گوید.

لیست از بالا به پایین:
- **OVERDUE**: کارهای گذشته (ردیف قرمز کمرنگ، `days late`). قدیمی‌ترین بالا است.
- نوار **Today** با تاریخ امروز.
- **INCOMING**: کارهای آینده در بازه انتخابی. نزدیک‌ترین بالا است.
- **⚪ LABEL WITHOUT DUE DATE – TO CHECK**: لیبل‌هایی که طوسی هستند و تاریخ ندارند. این‌ها را باید بررسی و تاریخ‌شان را در اکسل ثبت کنید.

هر ردیف: تعداد روز، کد تجهیز، نوع لیبل (با رنگش)، تاریخ، توضیحات، مکان، فاصله انجام، کاربر و آخرین امضا. **روی کد تجهیز بزنید** تا به تب Search برود و کارت کامل را ببینید.

### نکات مهم
- «امروز» از **تاریخ گوشی/کامپیوتر** گرفته می‌شود، نه از سلول Today's Date اکسل.
- تاریخ‌ها به صورت `روز.ماه.سال` نمایش داده می‌شوند. بالای صفحه تاریخ آخرین به‌روزرسانی داده‌ها نوشته شده است.
- سایت فقط نمایش می‌دهد. برای تغییر تاریخ یا اطلاعات باید فایل اکسل را اصلاح و آپلود کنید.

## ۲. آپدیت کردن داده‌ها (هر بار)

1. فایل اکسل جدید را (با هر اسمی) در پوشه‌ی `data/` ریپازیتوری آپلود کنید: **Add file ← Upload files ← Commit**.
2. بعد از حدود ۱ تا ۲ دقیقه به‌صورت خودکار تبدیل و منتشر می‌شود. صفحه را رفرش کنید.
3. **جدیدترین فایل داخل `data/` استفاده می‌شود.** فایل قبلی را می‌توانید پاک کنید یا بگذارید بماند.

### قواعد اکسل (برای اینکه سایت درست بخواند)
- شیت‌های لازم: `EQ` (داده‌ها) و `Personel` (اسم کامل کاربران). ستون‌ها بر اساس **اسم هدر** خوانده می‌شوند.
- **لیبل بدون تاریخ**: سلول تاریخ سررسید (ستون PM، CA یا PQ due date) باید **خالی** باشد و **رنگ طوسی** داشته باشد. وقتی تاریخ را بنویسید و رنگ را بردارید، در آپدیت بعدی از لیست طوسی‌ها خارج می‌شود.
- سلولی که خالی است ولی رنگ دیگری دارد (مثلاً زرد)، به‌عنوان «بدون تاریخ» شناخته نمی‌شود.
- ستون جدید در شیت EQ اضافه کنید ← خودکار در داده می‌آید. برای نمایش در کارت، `web/index.html` را ویرایش کنید.

## ۳. راه‌اندازی اولیه (فقط یک بار، حدود ۱۰ دقیقه)

1. در GitHub یک Repository بسازید (مثلاً `ec-equipment`) و **همه‌ی محتوای این پوشه** را آپلود کنید. پوشه‌ی `.github` هم باید باشد (در ویندوز اگر مخفی است، Show hidden files را بزنید).
2. در Repository: **Settings ← Pages ← Build and deployment ← Source = GitHub Actions**.
3. تب **Actions** را باز کنید. بعد از ۱ تا ۲ دقیقه آدرس سایت ظاهر می‌شود: `https://USERNAME.github.io/ec-equipment/`
4. آدرس را به همکاران بدهید.

**تست روی کامپیوتر:** `pip install openpyxl && python scripts/build.py` سپس `dist/index.html` را باز کنید.

**حریم خصوصی:** در GitHub Pages رایگان، آدرس سایت عمومی است. اگر داده‌ها محرمانه‌اند، به‌جای آن Cloudflare Pages + Cloudflare Access (رایگان تا ۵۰ کاربر) را استفاده کنید. همین پوشه بدون تغییر کار می‌کند (Build command: `pip install openpyxl && python scripts/build.py` ، Output: `dist`).

## ۴. مشکل‌یابی

| مشکل | راه حل |
|---|---|
| داده‌ها آپدیت نشد | تب **Actions** را ببینید که آخرین اجرا سبز باشد. بعد صفحه را hard refresh کنید. |
| یک لیبل طوسی در سایت «No date» نشان نمی‌دهد | سلول باید واقعاً خالی و طوسی باشد (نه زرد یا سفید). |
| تعداد overdue با اکسل فرق دارد | تاریخ دستگاه را چک کنید، چون سایت از تاریخ دستگاه استفاده می‌کند. |
| سایت خالی است | فایل `data.js` ساخته نشده. اجرای build را در Actions چک کنید. |
